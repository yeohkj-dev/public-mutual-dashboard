# Public Series Fund Dashboard

Live: <https://yeohkj-dev.github.io/public-mutual-dashboard/>

A static dashboard for Public Mutual funds:

- **Unit trust:** the "Public" series (excludes PB and Public e-Series), split into **EPF qualified** and **non-EPF**.
- **PRS:** Public Mutual Private Retirement Scheme funds, split into **conventional** and **Islamic**.

For every fund it shows the name, abbreviation, latest price (NAV) and price date, daily change, EPF status, asset class, region, theme, risk level, and performance over 1M / 3M / 6M / YTD / 1Y / 3Y p.a. / 5Y p.a. You also get Top 10 rankings, a 5-year price chart (compare up to 3 funds, optionally against a benchmark index), **top 10 holdings** with country / sector / asset-type breakdowns, and a **world markets** table and chart for reference.

## Data sources (all publicmutual.com.my)

| What | Where |
|---|---|
| Prices and price history | [Fund-Price-UT](https://www.publicmutual.com.my/Fund-Price-UT), [fund-price-prs](https://www.publicmutual.com.my/fund-price-prs) |
| EPF eligibility, risk level, distribution policy | [Fund Explorer](https://www.publicmutual.com.my/fund-explorer-list) |
| Holdings | Latest annual / semi-annual fund report from [Fund Report / Fund Fact Sheet](https://www.publicmutual.com.my/pmb/fund-report-fund-fact-sheet) |
| World indices (18: KLCI, S&P 500, Nasdaq, Hang Seng, Nikkei, MSCI World, gold…) | Yahoo Finance chart data (unofficial, no key) |

## Files

| Path | What it is |
|---|---|
| `index.html` | The dashboard (no build step, no dependencies) |
| `data/funds.js` | Prices and month-end history, generated by `fetch_data.py` |
| `data/holdings.js` | Holdings, generated by `fetch_holdings.py` |
| `scripts/fetch_data.py` | Prices for unit trust + PRS (Python 3, stdlib only) |
| `scripts/fetch_holdings.py` | Downloads each fund's latest report PDF and extracts holdings (needs `pymupdf`) |
| `data/indices.js` / `scripts/fetch_indices.py` | World indices: level, returns, weekly closes for 5 years |
| `.github/workflows/update-data.yml` | Runs all three scripts **every day at 12:00 noon Malaysia time** and commits the result |

## Refresh by hand

```bash
python scripts/fetch_data.py
```

```bash
pip install pymupdf
```

```bash
python scripts/fetch_holdings.py
```

```bash
python scripts/fetch_indices.py
```

`fetch_holdings.py` only re-downloads a fund's report when Public Mutual publishes a new one.

## Notes on the numbers

- Performance is **price return** from NAV; distributions are not added back, so income-paying funds look lower than their total return.
- 3Y and 5Y figures are annualised.
- Holdings come from the latest annual or semi-annual report, so they can be several months old. Money market reports don't list individual holdings.
- Region and theme are inferred from the fund name and Public Mutual's Local / Foreign / Mix mandate tag.
- Not investment advice. Past performance is not indicative of future performance.
