# Public Series Fund Dashboard

A static dashboard for Public Mutual's **"Public" series** unit trust funds (excludes PB and Public e-Series), split into **EPF qualified** and **non-EPF** funds.

It shows, for every fund: name, abbreviation, latest price (NAV) and price date, daily change, EPF status, asset class, region / market, theme, risk level, and performance over 1M / 3M / 6M / YTD / 1Y / 3Y p.a. / 5Y p.a. — with Top 10 rankings, a 5-year price chart (compare up to 3 funds), and breakdowns of where the funds invest.

Data source: <https://www.publicmutual.com.my/Fund-Price-UT> and the Fund Explorer on the same site.

## Files

| Path | What it is |
|---|---|
| `index.html` | The dashboard (no build step, no dependencies) |
| `data/funds.js` | Fund data, generated by the script below |
| `scripts/fetch_data.py` | Pulls latest prices, EPF flags and 5 years of month-end NAVs (Python 3, stdlib only) |
| `.github/workflows/update-data.yml` | Refreshes `data/funds.js` every weekday and commits it |

## Use it

Open `index.html` in a browser. To refresh the data:

```bash
python scripts/fetch_data.py
```

## Publish on GitHub Pages

1. Push this folder to a GitHub repository.
2. Repository **Settings → Pages → Build and deployment**: Source *Deploy from a branch*, branch `main`, folder `/ (root)`.
3. Repository **Settings → Actions → General → Workflow permissions**: *Read and write permissions* (so the daily refresh can commit).

## Notes on the numbers

- Performance is **price return** from NAV; distributions are not added back, so income-paying funds look lower than their total return.
- 3Y and 5Y figures are annualised.
- Region and theme are inferred from the fund name and Public Mutual's Local / Foreign / Mix mandate tag — check each fund's Product Highlights Sheet for its actual asset allocation.
- Not investment advice. Past performance is not indicative of future performance.
